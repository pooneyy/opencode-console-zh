# OpenCode Console 汉化插件

将 opencode.ai/console 界面自动翻译为简体中文，覆盖导航、按钮、表单、提示与报错信息，支持 SPA 动态渲染，可随时一键切换中英文。

## 安装方法

1. 安装浏览器插件
    - [Tampermonkey](http://tampermonkey.net/)
    - [Violentmonkey](https://violentmonkey.github.io/)
2. 安装脚本
    - [Github](https://github.com/pooneyy/opencode-console-zh/raw/refs/heads/main/main.user.js)
    - [GreasyFork](https://greasyfork.org/zh-CN/scripts/602346)
    - [jsdelivr](https://fastly.jsdelivr.net/gh/pooneyy/opencode-console-zh@main/main.user.js)
    - [jsdmirror](https://cdn.jsdmirror.com/gh/pooneyy/opencode-console-zh@main/main.user.js)
    - [ScriptCat](https://scriptcat.org/zh-CN/script-show-page/8749)

### 使用方法

1. 快捷键：Alt + Shift + Z
2. 油猴菜单：Tampermonkey 图标：“切换为英文 / 切换为中文”
3. 右下角悬浮按钮：单击切换中/英；双击暂时隐藏按钮，再次按下快捷键可恢复
